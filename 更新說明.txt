Subtitle Archive 公開網站 v2.3.1 更新方式

1. 解壓縮更新包。
2. 將 index.html、assets、scripts、data 與 README.md 上傳到 GitHub repository 根目錄。
3. 同名檔案請選擇取代。
4. 本更新包沒有 videos.json，請保留 GitHub 上原本的 data/videos.json。
5. 等 GitHub Actions 顯示綠色完成，再等約 1～3 分鐘後強制重新整理網站。

本次修正
- 首頁大圖改用獨立圖片元素載入，設定圖片失敗時自動恢復 assets/hero.webp。
- 影片內頁保留重複標題，同時恢復成員、影片類型與來源平台標籤。
- 免責聲明移到播放器與字幕控制區下方，與播放器同寬並置中。
- 更新檔案快取版本，避免瀏覽器繼續使用舊程式。

重要
- scripts/build.mjs 與 data/site-config.json 仍需保留。
- 請勿刪除或覆蓋原本的 data/videos.json。
